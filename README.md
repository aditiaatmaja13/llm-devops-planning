# LLM-assisted DevOps Planning (Guided Study)

This project compares three approaches for generating DevOps execution plans from underspecified operational requests:

- Variant A: Naive prompting
- Variant B: Structured prompting
- Variant C: Structured + grounded prompting (RAG-style)

Artifacts:
- `prompts/` prompt variants
- `data/requests/` fixed request set
- `evaluation/` rubric for plan quality evaluation
